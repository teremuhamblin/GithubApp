# 🗺️ ROADMAP — GithubApp
Plan d’évolution du projet GithubApp, de la version 5.0 à la version 7.0.

========================================
🟩 v5.0 — Stable (Terminé)
========================================
- ✔ Tests unitaires complets
- ✔ Documentation mise à jour
- ✔ Rules Engine optimisé
- ✔ Logs tactiques renforcés
- ✔ Nettoyage du code
- ✔ Gestion des erreurs améliorée

========================================
🟦 v6.0 — Monitoring & Dashboard TUI
========================================
🎯 Objectif : fournir une interface opérateur militaire pour surveiller le bot.

Fonctionnalités prévues :
- ✔ Dashboard TUI Ghost Recon
- ✔ Monitoring en temps réel (issues, PR, labels, merges)
- ✔ Logs filtrables (INFO / WARN / ERROR / DEBUG)
- ✔ Statistiques automatiques (stats.json)
- ✔ Mode opérateur avancé (Silent Ops, Recon Mode)
- ✔ Intégration dans CI/CD

Livrables :
- tui/dashboard.js
- monitoring/stats.json
- docs/TUI.md

========================================
🟨 v7.0 — Plugin Manager & Marketplace interne
========================================
🎯 Objectif : rendre GithubApp totalement modulaire.

Fonctionnalités prévues :
- ✔ Activation/désactivation dynamique des plugins
- ✔ Chargement automatique des modules externes
- ✔ Vérification des dépendances
- ✔ Marketplace interne (plugins communautaires)
- ✔ Système de permissions par plugin
- ✔ Documentation dédiée

Livrables :
- PluginManager.js
- plugins/registry.json
- docs/PLUGINS.md

========================================
🟧 v8.0 — (Prévisionnel)
========================================
Idées futures :
- IA interne pour classification des issues
- Analyse automatique du code
- Auto‑review des PR
- Génération automatique de documentation
